인스타그램 댓글 추출

인스타그램 이벤트 게시물의 댓글을 전부 모아 엑셀 파일로 만들어요. 댓글 ID 기준으로 중복은 자동으로 제거돼요.

⚠ 인스타그램은 로그인한 사용자에게만 댓글 전체를 내려주고, 외부 서버가 게시물 링크만으로 그 내부 API를 직접 호출하는 건 인스타그램의 인증·보안 정책상 막혀 있어요. 그래서 "링크만 입력하면 서버가 알아서 다 가져오는" 방식은 기술적으로 불가능해요 — 일부만 가져와 놓고 전체를 모은 것처럼 보여드리지 않으려고, 이미 검증된 방법을 그대로 자동화했어요. 아래처럼 브라우저에서 댓글을 전부 스크롤해 불러온 뒤 저장한 HAR 파일 하나만 올리면, 그 안의 모든 페이지 응답을 자동으로 찾아 모으고 정리해서 엑셀로 만들어드려요. 직접 하실 일은 "HAR 파일로 저장하기" 한 번뿐이에요.

HAR 파일 저장 방법

크롬 기준 4단계예요. 한 번 해두면 다음부터는 금방 익숙해져요.
STEP 01

게시물 열기

추출할 게시물을 크롬에서 열고, F12(개발자도구) → Network 탭을 열어요.

STEP 02

Fetch/XHR로 필터

Network 탭 상단 필터를 Fetch/XHR로 맞춰서 불필요한 이미지·스크립트 요청을 숨겨요.

STEP 03

댓글 끝까지 불러오기

게시물의 댓글 영역을 맨 아래까지 스크롤해서 "더 보기"가 사라질 때까지 모든 댓글을 불러와요.

STEP 04

HAR로 저장

Network 탭 목록에서 우클릭 → "Save all as HAR with content"를 눌러 .har 파일로 저장해요.
