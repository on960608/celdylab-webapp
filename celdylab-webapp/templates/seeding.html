시딩 업무 가이드

협찬 인원 리스트업부터 가이드 제작 및 검수까지, 시딩 운영의 전체 단계별 기준입니다. 실제 반응점수 계산과 후보 관리는 협찬 인원 리스트업 페이지에서, 업로드 후 성과 기록은 시딩 인사이트 분석 페이지에서 진행하세요.

STEP 00. 업무 시작 전 준비

콘텐츠팀 구글 드라이브 접속

  • 콘텐츠팀 구글 계정 로그인
  • 콘텐츠팀 구글 드라이브 접속
  • 진행할 브랜드 / 제품 확인
  • 업무 포털에서 해당 시딩 제품명 클릭
  • 연결된 구글 드라이브에서 해당 제품의 시딩 업무 자료 확인

업무 포털 구성 — 제품명을 클릭하면 해당 제품의 구글 드라이브 폴더로 바로 연결될 수 있도록 구성합니다.

콘텐츠팀 구글 계정 로그인 화면
콘텐츠팀 구글 드라이브 폴더 목록

STEP 01. 인플루언서 리스트업 — 1-1. 리스트업 시트 만들기

구글 드라이브에서 아래 순서로 진행합니다.
시딩 업무 → 인플루언서 서치 → 인플루언서 리스트 → 리스트업 시트 사본 만들기 → 인원 기입

리스트업 시트 사본 만들기
인플루언서 서치 → 인플루언서 리스트 폴더

리스트업 목표 — 1일 기준 최소 20명 / 목표 30명 이상. 단순히 인원수를 채우는 것이 아니라 아래 선정 기준과 탈락 기준을 확인한 후 리스트업합니다.

STEP 02. 인플루언서 서치 — 2-1. 인플루언서 찾는 방법

시딩 제품의 브랜드 인스타그램 계정으로 로그인 후 진행합니다.

방법 ① 관련 카테고리 및 해시태그 검색
제품과 연관된 타깃과 카테고리를 먼저 설정합니다.
예시: 리빙 제품 → 리빙 / 자취생 / 청소 / 살림 / 세정 등. 제품을 실제 사용할 가능성이 높은 타깃을 기준으로 관련 해시태그와 계정을 확장하여 탐색합니다.

방법 ② 협찬이 활발한 브랜드 역추적

  • 동일·유사 카테고리 브랜드 확인
  • 해당 브랜드의 협찬 콘텐츠 확인
  • 협찬을 진행한 인플루언서 확인
  • 자사 제품과 적합한 인플루언서 리스트업

방법 ③ 공구·시딩 플랫폼 활용
공구 및 시딩 진행 어플에서 유사 제품의 진행 사례를 확인하고, 진행했던 인플루언서를 역추적하여 리스트업합니다.

방법① #리빙 해시태그 검색
방법① #청소 해시태그 검색
방법② 협찬 게시물 확인
방법② 브랜드 프로필 역추적
방법③ 공구·시딩 플랫폼(09now) 활용

STEP 03. 인플루언서 선정 기준 — 3-1. 기본 선정 기준

⭐ 최근 선정 기준 — 반응점수 1,000점 이상을 기본 선정 기준으로 진행합니다. 팔로워 수만 확인하지 않고 최근 콘텐츠의 조회수 / 댓글 / 공유 등 실제 반응과 구매 전환 가능성을 함께 확인합니다.

반응점수 확인 시 주의사항

  • 업로드 후 24시간이 지나지 않은 게시물은 제외
  • 상단 고정 게시물은 제외
  • 최근 업로드된 일반 게시물을 기준으로 확인

STEP 04. 리스트업 탈락 기준

아래 기준에 해당하는 계정은 리스트업에서 제외합니다.

  • ① 최근 릴스 조회수가 낮은 계정 — 최근 3개 릴스의 조회수가 1만 미만이거나 팔로워 대비 현저하게 낮은 경우 제외 (예: 팔로워 3만 → 최근 릴스 조회수 1만 이하 지속 → 탈락)
  • ② 추종 댓글이 없는 계정 — 정보/제품/구매 문의 등 실제 관심을 보이는 댓글이 없는 계정은 제외. 단순 품앗이성 댓글은 유효 반응으로 판단하지 않음
  • ③ 좋아요에 비해 실제 반응이 낮은 계정 — 좋아요 수는 높지만 댓글·공유 등 실제 반응이 현저하게 낮은 경우 제외 (예: 좋아요 3,000 / 댓글 10 / 공유 2 → 탈락 검토)
  • ④ 협찬 콘텐츠의 반응이 낮은 계정 — 일반 콘텐츠 대비 협찬 게시물만 조회수가 낮거나 댓글 반응이 없는 경우 광고 효과가 낮은 계정으로 판단하여 제외
  • ⑤ 최근 활동이 없는 계정 — 최근 게시물 또는 릴스의 업로드일이 2주 이상 지난 계정은 제외

STEP 05. 협찬 리스트 시트 작성

5-1. 리스트업 인원 입력 — 선정한 인플루언서를 협찬 리스트 시트에 입력합니다. 리스트는 반응점수가 높은 순서대로 정렬합니다.

협찬 리스트 시트 작성 예시

5-2. 반응점수에 따른 표시 — 1,000점 이상 → ⭕ / 1,000점 미만 → ⛔

예외 진행 — 반응점수가 1,000점 미만이지만 협찬 진행 가치가 있다고 판단되는 경우에는 반드시 '제안 사유'를 작성합니다.

  • 제품 타깃과 콘텐츠 카테고리가 정확하게 일치
  • 유사 제품 콘텐츠 반응이 높음
  • 댓글 내 제품 및 구매 문의가 활발함
  • 콘텐츠 연출력이 뛰어나 2차 활용 가치가 높음

STEP 06. 인사이트 점수(반응점수) 작성

6-1. 최근 콘텐츠 인사이트 입력 — 최근 릴스 3개의 데이터를 확인하여 시트에 입력합니다. 조회수 1 / 조회수 2 / 조회수 3 → 각 인플루언서의 최근 릴스 게시물 순서대로 입력. 조회수뿐만 아니라 댓글 / 공유 수도 함께 입력합니다. 공유 수는 모바일 인스타그램에서 확인이 필요합니다.

최근 게시물 3개 인사이트 입력

6-2. 반응점수 확인 — 시트 내 2번 탭 '반응점수 환산'을 클릭합니다. 입력한 최근 3개 게시물 데이터를 기준으로 평균 조회 / 댓글 / 공유 수가 자동 환산되어 최종 반응점수가 계산됩니다.

'반응점수 환산' 탭에서 최종 점수 확인

6-3. 확장 프로그램으로 인사이트 점수 확인 — 크롬 확장 프로그램 'ig-insight-overlay'를 설치하면 인스타그램 화면에서 바로 게시물 인사이트 점수를 확인할 수 있습니다.

  1. chrome://extensions 열기
  2. ig-insight-overlay 압축 파일(zip) 다운로드 후 압축 풀기
  3. 압축 푼 ig-insight-overlay 폴더를 chrome://extensions 화면으로 드래그해서 불러오기
  4. ig-insight-overlay 확장 프로그램이 등록됐는지 확인
  5. 인스타그램에 정상 적용됐는지 확인
ig-insight-overlay 확장 프로그램 설치 과정

STEP 07. 리스트업 검토 요청

리스트업이 완료되면 바로 DM을 발송하지 않고 검토 완료 후 발송합니다.

아르바이트 인원

  • 오후 1시 30분까지 협찬 리스트 시트 작성
  • 인플루언서 시딩 단톡방에 협찬 리스트 시트 공유
  • 담당자 검토 요청
  • 검토 완료 인원 확인
  • 승인된 인원에게 Instagram DM 발송

직원

  • 리스트업 완료
  • 직원 마케팅 단톡방에 협찬 리스트 시트 공유
  • 담당자 검토 요청
  • 검토 완료 인원 확인
  • 승인된 인원에게 Instagram DM 발송
🖼 이미지 자리 — 단톡방 검토 요청 예시

STEP 08. 인플루언서 DM 발송

8-1. 협찬 DM — 인플루언서 매니저 → DM 카테고리에서 진행 제품에 맞는 시딩 DM을 확인합니다.

  • 진행 제품별 시딩 DM 클릭
  • 인플루언서 이름 입력
  • 이름 자동 변환 확인
  • 완성된 본문 복사
  • 해당 인플루언서 Instagram DM으로 발송
인플루언서 매니저 → DM 카테고리 선택
제품별 DM 템플릿 확인
완성된 DM 본문 확인
본문 복사 후 발송

8-2. 공구 DM — 공구 제안의 경우 공구 DM 카테고리에서 해당 멘트를 확인합니다.

  • 공구 DM 확인
  • 인플루언서 이름 및 필요한 정보 입력
  • 본문 복사
  • 해당 인플루언서에게 DM 발송

STEP 09. 이메일 / 인포크 추가 발송

Instagram DM만 발송하고 종료하지 않습니다. 인플루언서 프로필에 아래 정보가 있다면 추가 컨택을 진행합니다. Instagram DM + 이메일 + 인포크

  • 프로필 내 이메일 확인 → 이메일 추가 발송
  • 인포크 링크가 있는 경우 → 인포크를 통한 추가 제안
  • 발송 완료 후 컨택 리스트에 발송 방법 기록
🖼 이미지 자리 — 프로필 이메일 / 인포크 확인 위치

STEP 10. 컨택 리스트 작성

DM 및 추가 컨택이 완료된 인원은 컨택 리스트업 엑셀 파일에 반드시 기록합니다.

필수 기재 내용

  • 인플루언서명
  • Instagram 계정
  • 컨택 방법
  • 컨택 일자
  • 진행 제품
  • 회신 여부
  • 진행 여부
  • 제안 단가
  • 이슈 사항 및 특이사항

회차 관리 — 시딩 진행 회차에 맞춰 새로운 탭을 추가하여 관리합니다. 기존 진행 인원과 신규 진행 인원이 섞이지 않도록 회차별로 구분합니다.

컨택 리스트업 엑셀 작성 예시

리스트업 → 컨택 완료 기준

① 제품 확인 → ② 인플루언서 서치 → ③ 선정·탈락 기준 확인 → ④ 최근 3개 콘텐츠 인사이트 입력 → ⑤ 반응점수 1,000점 기준 확인 → ⑥ 협찬 리스트 작성 및 반응점수 순 정렬 → ⑦ 담당자 검토 요청 → ⑧ 승인 인원 DM 발송 → ⑨ 이메일 / 인포크 추가 발송 → ⑩ 컨택 리스트 기록

STEP 11. 회신 확인 및 조건 협의

컨택 이후 인플루언서 회신을 확인하고 조건을 협의합니다. 이어지는 조건 확정 절차는 조건 확정 탭에서 확인하세요.

컨택 시 체크 포인트

  • 첫 DM에서 브랜드·제품·협업 형태(시딩/공구)를 명확히 안내
  • 회신이 없으면 3~5일 뒤 1회 리마인드
  • 회신 시 팔로워 수·최근 반응률 스크린샷 요청

STEP 12. 진행 조건 확정

협의된 조건(제공 내역·콘텐츠 형태·업로드 일정 등)을 최종 확정합니다. 아래 DM 예시와 조율 기준을 참고하세요.

단가 조율 DM 예시

안녕하세요, [인플루언서명]님. 관심 가져주셔서 감사합니다! 저희가 준비한 조건은 아래와 같아요. - 진행 형태: [시딩/공구] - 제공 내역: [제품/원고료/수수료] - 콘텐츠 형태: [릴스/피드/스토리 등] - 업로드 일정: [날짜] 혹시 생각하시는 조건이 있다면 편하게 말씀해 주세요. 조율 가능한 범위에서 맞춰볼게요!

조율 시 참고 기준

  • 팔로워·평균 조회수 대비 시장 단가 범위 확인 후 제안
  • 원고료 대신 제품+수수료 조건도 함께 안내
  • 조율 완료되면 반드시 최종 조건을 텍스트로 다시 한번 정리해서 상호 확인

STEP 13. 구글폼 작성 요청

확정된 조건을 바탕으로 정산·배송 정보를 받는 구글폼 작성을 요청합니다.

구글폼 발행 가이드

  • 이름, 연락처, 주소(배송용), SNS 계정, 정산 정보(계좌/사업자 여부)를 받는 구글폼을 준비
  • 폼 제출 완료 즉시 계약서 초안 발송

STEP 14. 계약서 발행

진행 유형(시딩/공구/플래그십)과 정산 방식에 맞는 계약서를 준비해 워드로 다운로드하고 발송합니다.

STEP 15. 제품 발송 및 진행 관리

  • 제품 발송 정보(주소·연락처) 재확인 후 발송
  • 발송 후 트래킹 번호 공유
  • 진행 중 회신 지연·이슈 발생 시 컨택 리스트에 즉시 기록

STEP 16. 가편본 전달 및 검수

인플루언서가 전달한 가편본을 아래 체크리스트로 검수합니다.

가편본 검수 체크리스트

  • 필수 멘트·필수 장면 포함 여부
  • 제품명·브랜드명 노출이 명확한지
  • 콘텐츠 톤이 가이드와 계약 조건에 맞는지
  • 워터마크·타 브랜드 노출 등 이슈 요소 확인

STEP 17. 수정본 확인

  • 요청한 수정 사항이 모두 반영됐는지 확인
  • 추가 수정이 필요하면 구체적으로 재요청
  • 최종 승인 후 업로드 일정을 다시 한번 확인

STEP 18. 최종 업로드

업로드 체크리스트

  • 업로드 일정·시간대 재확인
