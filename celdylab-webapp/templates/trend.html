외부몰 트렌드 분석

공구 앱에서 확인한 인기 셀러·제품과, G마켓·네이버·쿠팡 마켓플레이스의 카테고리별 제품 순위(베스트셀러/검색량)를 한 곳에서 확인해요. 공구 셀러 트렌드와 G마켓 탭은 페이지를 새로고침할 때마다 자동으로 최신 상태로 갱신돼요.

5개 공구 앱(82market·지금하는공구·공구모아·공구팡팡·맘캘린더)에서 확인한 인기 셀러·제품을 기록하면, 인기 셀러 분석과 카테고리별 인사이트가 자동으로 집계돼요. 이전 자동 데이터는 새 데이터로 교체되고, 직접 등록한 기록은 그대로 남아요. 지금 바로 갱신하고 싶으면 아래 "⚡ 자동 생성" 버튼을 눌러도 돼요.

HAR 파일로 쿠팡 순위 올리기

쿠팡은 자동화 도구 접속이 막혀 있고 공식 검색량 API도 없어서, 직접 로그인한 브라우저에서 저장한 HAR 파일을 올려서 순위를 반영해요(검색수 없이 쿠팡 자체 순위만 표시돼요).
  1. 크롬에서 쿠팡에 로그인 → 반영하고 싶은 카테고리의 베스트/랭킹 페이지로 이동해요.
  2. 상품이 다 보이도록 페이지를 끝까지 스크롤해요.
  3. F12(개발자도구) → Network 탭 → 페이지를 새로고침 → 요청 목록에서 우클릭 → "Save all as HAR with content"로 저장해요.
