# 셀디랩 콘텐츠팀 웹앱 (v1: 로그인 + 자료실)

지금까지 쓰던 "파일 하나 다운로드해서 Netlify에 올리는" 트래커와는 구조가 완전히 달라요.
이건 로그인이 있고, 실제 서버에 있는 데이터베이스(DB)에 저장하는 **진짜 웹앱**이에요.
그래서 배포도 "파일 드래그"가 아니라 아래 순서대로 진행해주셔야 해요.

## 이번 버전에 들어있는 것

- 로그인 (직원 계정, 비밀번호는 안전하게 암호화되어 저장돼요)
- 자료실 — 브랜드·제품별 구글 드라이브 링크. 로그인한 사람이 수정하면 **진짜 DB에 저장**되어, 다른 사람이 새로고침하면 바로 보여요 (구글 시트 경유 없이 웹앱 안에서 바로 수정)
- 왼쪽 메뉴에 "시딩 업무 가이드", "공구 업무 가이드"는 자리만 만들어뒀어요 (다음 버전에서 채울게요)

## 로컬에서 미리보기 (선택사항)

컴�터에 Python이 설치되어 있다면:

```bash
pip install -r requirements.txt
python3 seed.py          # 최초 1회: DB 생성 + 기본 브랜드/제품 + 데모 계정
python3 app.py           # http://127.0.0.1:5000 에서 확인
```

데모 계정: `admin` / `celdylab2026` (꼭 로그인 후 직접 새 계정을 만들고, 이 데모 계정은 잊어주세요)

## 배포하기 — Railway 추천

**왜 Netlify가 아니라 Railway인가요?** 이 웹앱은 로그인 정보와 자료실 데이터를 실제로 저장해야 해서,
파일만 올리는 Netlify로는 안 돼요. Railway는 GitHub 저장소를 연결하면 자동으로 실행해주고,
데이터를 안전하게 보관할 저장공간(Volume)도 몇 번의 클릭으로 붙일 수 있어요.

**비용 안내**: 처음 가입하면 30일간 5달러 무료 크레딧을 줘요. 이후에는 이 정도 작은 앱 기준
한 달에 약 1~5달러 정도예요 (커피 한 잔보다 저렴해요). 완전 영구 무료 호스팅은 아니라는 점만 참고해주세요.

### 1단계 — GitHub에 코드 올리기

1. [github.com](https://github.com) 에서 계정을 만들고 로그인하세요 (이미 있으면 생략)
2. 오른쪽 위 **+** → **New repository** 클릭 → 이름을 `celdylab-webapp` 정도로 짓고 **Create repository**
3. 그 저장소 페이지에서 **uploading an existing file** 링크를 클릭 → 이 폴더 안의 파일 전체를 끌어다 놓기 → **Commit changes**

### 2단계 — Railway 계정 만들고 배포

1. [railway.com](https://railway.com) 접속 → **Login with GitHub**로 가입
2. **New Project** → **Deploy from GitHub repo** → 방금 만든 `celdylab-webapp` 선택
3. 배포가 시작되면 프로젝트 화면에서 방금 만든 서비스 카드를 클릭하고 **Variables** 탭으로 이동해서 아래 두 값을 추가하세요.
   - `SECRET_KEY` = 아무 임의의 긴 문자열 (예: `celdylab-2026-secret-키를아무거나길게`)
   - `DATABASE_PATH` = `/data/celdylab.db`
4. 같은 서비스에서 **Settings → Volumes → New Volume** 클릭 → Mount path에 `/data` 입력 → 저장.
   (이 저장공간이 있어야 서버가 재시작돼도 자료실에 저장한 링크가 사라지지 않아요.)
5. 다시 배포되기를 기다렸다가, **Settings → Networking → Generate Domain**을 눌러 주소를 하나 발급받으세요. 그 주소로 접속하면 로그인 화면이 떠요.

### 3단계 — 첫 로그인 & 직원 계정 만들기

1. 발급받은 주소로 접속해서 데모 계정(`admin` / `celdylab2026`)으로 먼저 로그인해보세요.
2. 실제 직원 계정을 만들려면, Railway 프로젝트의 서비스 화면에서 **Shell** (또는 커맨드 실행 메뉴)을 열고 아래 명령을 입력하세요.
   ```bash
   python3 add_employee.py hh 희현
   ```
   아이디(`hh`)와 이름(`희현`)은 원하는 값으로 바꾸면 되고, 실행하면 비밀번호를 물어봐요.
3. 다 만든 뒤에는 데모 계정을 지우는 걸 추천해요 (다음 버전에서 계정 관리 화면을 만들어드릴게요).

## 앞으로 확장할 때

`app.py`에 `# 앞으로 채워질 페이지들` 주석 아래에 새 라우트를 추가하는 방식으로 시딩 → 공구 → 인플루언서
컨택관리를 하나씩 붙일 예정이에요. `db.py`는 SQLite를 쓰고 있는데, 나중에 데이터 양이 많아지면
같은 함수 구조를 유지한 채로 Postgres로 바꿀 수 있도록 만들어뒀어요.
